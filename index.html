Firebase সেটআপ

  1. Firebase Console → Authentication-এ Email/Password চালু করুন। Users → Add user দিয়ে আপনার ও টিমের অ্যাকাউন্ট তৈরি করুন।
  2. প্রতিটি ব্যবহারকারীর UID কপি করুন। Realtime Database → Data-এ atlasMembers/USER_UID পাথে boolean true যোগ করুন। USER_UID-এর জায়গায় আসল UID বসাবেন। অ্যাপ নিজে কাউকে অনুমতি দিতে পারে না।
  3. Realtime Database → Rules-এ নিচের নিয়ম অন্য বিদ্যমান নিয়মের সঙ্গে মিলিয়ে বসিয়ে Publish করুন। আগে থেকে root-level read/write true থাকলে সেটি বন্ধ করুন, নইলে নিচের বিধিনিষেধ কার্যকর হবে না। 
{
  "rules": {
    ".read": false,
    ".write": false,
    "atlasMembers": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid"
      }
    },
    "srAtlas": {
      ".read": "auth != null && root.child('atlasMembers').child(auth.uid).val() === true",
      ".write": "auth != null && root.child('atlasMembers').child(auth.uid).val() === true"
    }
  }
}

৪. HTML-টি HTTPS হোস্টিংয়ে চালান। Authentication → Settings → Authorized domains-এ হোস্টিং ডোমেইন যোগ করুন। লগইন করে SR ও দোকান যোগ করুন। তথ্য srAtlas-এ থাকবে। ছবি ছোট JPEG হিসেবে একই ডাটাবেইজে থাকবে; আলাদা Storage সেটআপ লাগবে না।

পুরনো ফোনের তথ্য আনুন

আগের HTML যে browser ও একই website origin-এ চলেছিল সেখানেই এই ফাইল চালিয়ে লগইন করুন। পুরনো localStorage থেকে SR ও দোকান একবার আমদানি হবে। নতুন সিরিয়াল দেওয়া হবে; পুরনো তথ্য মুছবে না। ভিন্ন origin হলে পুরনো HTML থেকে আগে JSON export করতে হবে।

ম্যাপ সম্পর্কে

লেবেলসহ OpenStreetMap ব্যবহার করা হয়েছে। রাস্তা ও ছোট জায়গার নাম দেখতে + দিয়ে জুম করুন। SR-এর বাইরেও ম্যাপ পরিষ্কার থাকবে। OSM-এ যে নাম নেই তা দেখানো সম্ভব নয়। দোকানের Google Maps বাটন দিয়ে Google navigation খুলতে পারবেন। প্রকৃত Google basemap চাইলে আলাদা Google Maps JavaScript API key ও billing setup প্রয়োজন।

দোকান যোগ: ম্যাপের ভেতরে জায়গা ট্যাপ করুন, তারপর + দোকান। নিজের বর্তমান জায়গায় যোগ করতে আগে ◎ চাপুন। সীমানা: + কোণা → ম্যাপ ট্যাপ → কমলা বৃত্ত টেনে সরান। জুম / সরান চালু করলে ম্যাপ নড়বে।

ইন্টারনেট বা অনুমতি না থাকলে সংরক্ষণ বন্ধ থাকবে। সফল Firebase confirmation-এর পরেই “সংরক্ষণ হয়েছে” দেখাবে। এই ফাইল আপনার Firebase Console-এর settings বা rules নিজে পরিবর্তন করে না।
